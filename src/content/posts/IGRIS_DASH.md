## Overview

IGRIS is a local-first personal productivity platform designed to track daily habits, study sessions, and personal progress while analyzing behavioral patterns.

It combines habit tracking, productivity analytics, and Python-based behavioral analysis to generate insights such as momentum scores, burnout risk estimation, productivity predictions, and habit correlations.

Built with privacy in mind, all user data is stored locally, with no cloud dependency or external account required.

## Architecture

IGRIS follows a lightweight local architecture:

| Layer | Technology |
|---|---|
| Frontend | HTML, CSS, Vanilla JavaScript |
| Visualization | Chart.js |
| Backend | Node.js |
| Data Storage | Local JSON files |
| Behavioral Analysis | Python 3 |

The Node.js server handles local application functionality, while the Python analysis engine processes historical activity data and generates behavioral insights.
